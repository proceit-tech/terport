# TERPORT V2 — Menus novos aperfeiçoados

Este pacote foi revisado com base no Documento de Requerimientos Sistema Tarifario v2.0.

- Dashboard
- Cálculo de Tasas
- Clientes
- Tarifas
- Servicios y Artículos
- Matriz de Servicios
- Pedidos
- Proformas

Cálculo de Tasas + Proformas serão revisados em uma etapa separada.

## Melhorias principais

- Agenda semanal com meta e cumprimento por representante.
- Reagendamento e acompanhamento de compromissos.
- Próxima ação estruturada para permitir estatísticas.
- Resultado comercial estruturado.
- Histórico de carteira e clientes sem representante.
- Alertas configuráveis de clientes sem contato.
- Perfis Representante, Supervisor, Administrador e Director.
- Auditoria com valor anterior e valor novo.
- Indicação explícita da definição pendente sobre origem dos vendedores.
- Integrações Waldbott e NAVIS separadas por finalidade e modo.
- Configuração de período de alerta, objetivo semanal e notificação consolidada.

## Instalação

1. Extrair o ZIP.
2. Copiar o conteúdo para a raiz do projeto.
3. Aceitar substituir somente os arquivos presentes no pacote.
4. Parar o servidor Next.js.
5. Apagar a pasta `.next`.
6. Executar `npm run dev`.

Todos os arquivos foram formatados para leitura e manutenção humana.
