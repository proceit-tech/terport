# Integraciones

## Waldbott

Estructura prevista para:

- Sincronización incremental de clientes.
- Tipo de cambio.
- Creación de pedidos.
- Estado de pedidos.
- Anulación.
- Recepción futura de eventos/webhooks.

## NAVIS

Estructura prevista para:

- Consulta de contenedores.
- Tamaño.
- Fecha/hora de ingreso.
- Condición refrigerada/enchufada.
- Precinto.
- Apertura.
- Verificación.
- Eventos operativos.
- Matching con el cálculo tarifario.

## Configuración

La pantalla visual se encuentra prevista en:

`app/(app)/settings/integrations/page.tsx`

No se implementan credenciales ni conectividad real hasta recibir la especificación técnica de cada sistema.
